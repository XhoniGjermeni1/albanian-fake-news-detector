# Historical Model Artifacts

Kjo dosje mban lokalisht modelet e vjetra të Ditëve 2–16 për
riprodhueshmëri. Skedarët `*.joblib` vazhdojnë të injorohen nga Git sepse janë
artefakte binare të rigjenerueshme. Runtime-i nuk ngarkon asnjë prej tyre.

Modeli i vetëm aktiv dhe i versionuar mbetet:

```text
models/final_word_char_linear_svm_calibrated_v1.joblib
```

Path-et e modeleve historike brenda manifestit final dokumentojnë vendndodhjen
që kishin kur u ngri versioni `v1.0.0`; modeli dhe manifesti nuk janë
rishkruar gjatë riorganizimit.
