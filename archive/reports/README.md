# Archived Reports

Kjo dosje përmban raportet ditore, CSV/JSON diagnostike dhe figurat historike
që dokumentojnë evolucionin e projektit. Ato nuk lexohen nga runtime-i final.

Rezultatet zyrtare të diplomës janë centralizuar te `reports/final/`.
Kontrollet teknike të ngrirjes, integrimit, regresionit dhe mbylljes janë
grupuar te `finalization/`.
